# Phase 1 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Mode:** `--auto`. No user was available. Every value below is either (a) a locked CONTEXT.md decision (cited as D-nn), (b) inherited from the sibling site `patrickclery.github.io` (cited as "sibling"), or (c) an auto-selected default — all defaults are listed in the final section "Auto-selected defaults" for audit.

**Scope:** Root layout (header, footer), sticky toolbar, filter chip groups, mobile bottom sheet, result-count line, poster grid, poster card (normal / placeholder / SOLD / Reserved), empty state, Suspense loading skeleton. Detail pages, mailto CTA, and OG meta are Phase 2 and are NOT specified here.

## Spacing Scale

Declared values (must be multiples of 4). Tailwind v4 default scale is 4px-based, so `p-1 = 4px`, `p-2 = 8px`, `p-3 = 12px`, `p-4 = 16px`, `p-6 = 24px`, `p-8 = 32px`, `p-12 = 48px`, `p-16 = 64px`.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Gap between chips inside a card caption; gap between icon and text inside a badge |
| sm | 8px | Toolbar control gap; chip-row gap; card caption padding at base; vertical rhythm inside card caption |
| md | 16px | Page horizontal padding at base (`px-4`); card caption padding at `sm+` is 12px (`p-3`); gap between filter groups in the sheet |
| lg | 24px | Header vertical padding; page horizontal padding at `sm+` (`px-6`); gap between chip groups on the desktop chip row; sheet body padding |
| xl | 32px | Space between header and toolbar; placeholder-card `Film` icon size |
| 2xl | 48px | Space between grid and footer; grid bottom padding |
| 3xl | 64px | Empty-state vertical padding |

**Grid gap:** 12px (`gap-3`) at base, 16px (`gap-4`) at `sm+` (D-20 "gap 3–4"). 12 is a multiple of 4 and is declared here as the one intermediate value.

**Exceptions:**
- **Touch targets:** every interactive control (chips, segmented buttons, search input, sort select, Filters button, sheet close, sheet apply, Clear all, Clear filters) is `min-h-11` (44px) at base (D-20). At `md+` chips and segmented buttons may reduce to `h-9` (36px) because the pointer is a mouse; the 44px minimum stays for everything else.
- **Badges** (rating, price, condition, Reserved) are 20px tall (`h-5`) — they are non-interactive, so the 44px rule does not apply.
- **Card min caption title height:** 2 lines × 14px × 1.5 = 42px (`min-h-[42px]` via `line-clamp-2` + fixed line-height) so single-line titles do not misalign chip rows across a grid row. 42 is not a multiple of 4; it is derived from typography, not the spacing scale, and is the only such value.

## Typography

Exactly four sizes, exactly two weights.

| Role | Size | Weight | Line Height | Font | Used by |
|------|------|--------|-------------|------|---------|
| Label | 12px (`text-xs`) | 700 | 1.33 (16px) | Space Grotesk | Rating badge, price chip, condition chip (400), Reserved pill, SOLD ribbon, desktop chip-group labels (uppercase, `tracking-wider`), footer attribution (400) |
| Body | 14px (`text-sm`) | 400 | 1.5 (21px) | Space Grotesk | Card title (700, Archivo), card meta line (year), filter chips, sort select, search input text, result-count line, Clear all, seller blurb, empty-state body, header counts line |
| Heading | 16px (`text-base`) | 700 | 1.25 (20px) | Archivo | Bottom-sheet title "Filters", sheet group headings ("Genre", "Decade", "Rating", "Availability"), empty-state heading "No matches", "Show N results" button label (Space Grotesk) |
| Display | 28px (`text-[28px]`) | 700 | 1.2 (34px) | Archivo | Header site title only. Does not scale up at larger breakpoints (single value keeps the count to four) |

**Weights:** 400 (regular) and 700 (bold) only. No 500/600. Sibling uses `font-bold` on headings — matched.

**Rules:**
- Card title: 14px / 700 / Archivo / `line-clamp-2` / `min-h-[42px]`. Never truncates to one line; never grows past two.
- Chips and buttons: 14px / 700 when selected, 14px / 400 when not. Weight is a state signal in addition to color.
- `letter-spacing`: only the 12px uppercase group labels and the SOLD ribbon use `tracking-wider` (0.05em). Nothing else.
- Numbers (prices, ratings, counts): `tabular-nums` so columns of cards align.

## Layout & Surfaces

### Root layout (`src/app/layout.tsx`)

```
<body class="min-h-dvh flex flex-col bg-bg text-text font-[family-name:var(--font-space-grotesk)] antialiased">
  <header>          (see Header)
  <main class="flex-1">{children}</main>
  <footer>          (see Footer)
</body>
```

Container everywhere: `mx-auto max-w-7xl px-4 sm:px-6` (D-20 `max-w-7xl`).

### Header (server component)

- Padding `py-6` (24px). Not sticky.
- Row 1: `<h1>` site title — Display 28px/700 Archivo, `tracking-tight`. Copy: **"DVDs for Sale"**.
- Row 2 (`mt-1`): counts line — Body 14px/400 muted, `tabular-nums`. Copy: **"{available} available · {total} total"** where `available` counts `status ∈ {available, reserved}` and `total` counts all entries (D-02, D-32). Computed at build time in the server component.
- Row 3 (`mt-4`, only rendered when `seller.blurb` is a non-empty string): blurb paragraph — Body 14px/400 muted, `max-w-2xl leading-relaxed`. Plain text; no markdown parsing. Empty/absent blurb renders nothing — no placeholder copy, no reserved height.
- No nav links, no logo in Phase 1.

### Sticky toolbar (client component, inside the Suspense boundary)

- `sticky top-0 z-20 border-b border-border bg-bg/95 backdrop-blur` — stays pinned while the grid scrolls (D-21). The header scrolls away.
- Inner: container padding + `py-2` (8px).
- **Row A** (`flex items-center gap-2`, height 44px):
  - Search input (`flex-1`): `<input type="search" inputMode="search" autoComplete="off" spellCheck={false}>`, `h-11 rounded-lg border border-border bg-surface pl-10 pr-3 text-sm text-text placeholder:text-text-muted focus:border-accent focus:outline-none`. `Search` icon 16px muted, absolutely positioned left 12px. `aria-label="Search titles"`, placeholder **"Search titles…"**. Value mirrors `?q=`. Native clear (x) of `type="search"` is acceptable; no custom clear button.
  - Sort select: native `<select>` `h-11 rounded-lg border border-border bg-surface px-3 pr-8 text-sm text-text` with visually-hidden `<label>` **"Sort by"**. Width: `w-auto` at base (shows current option only), `md:w-40`. Options in order: **Popularity**, **Rating**, **Year**, **Title** (D-22). Use the native arrow; do not overlay a custom icon (avoids double arrows on iOS).
  - Filters button (`md:hidden`): `<button>` `h-11 rounded-lg border border-border bg-surface px-3 text-sm inline-flex items-center gap-2`. `SlidersHorizontal` icon 16px. Label **"Filters"**; when active filter count n > 0, append a 20px round count badge (`h-5 min-w-5 px-1 rounded-full bg-accent text-bg text-xs font-bold tabular-nums`) so the accessible name reads "Filters, 2 active" (`aria-label`). Active count = number of genre chips selected + decade chips selected + (rating ≠ Any ? 1 : 0) + (availability ≠ Available ? 1 : 0). Search and sort do NOT count.
- **Row B** (`hidden md:flex`, `mt-2`, `overflow-x-auto` with `scrollbar-width: thin`, `gap-6` between groups, `gap-2` between chips inside a group, `pb-1`): the four chip groups in this order — **Availability**, **Genre**, **Decade**, **Rating**. Availability first because it is the one that changes what "total" means. Each group is prefixed by a Label 12px/700 uppercase muted `tracking-wider` text ("Availability", "Genre", "Decade", "Rating") that is part of the group's `<fieldset><legend>`.
- Row B is never rendered at base; the same groups render inside the bottom sheet instead. One `FilterChips` component; the toolbar row and the sheet are two containers (D-21).

### Result-count line

- `flex items-center justify-between py-2 mt-2` inside the container, directly above the grid.
- Left: `<p aria-live="polite" aria-atomic="true">` Body 14px muted `tabular-nums`. Copy: **"Showing {shown} of {total}"** — `total` is the full catalog count (all statuses), matching the header's `M total`, so "Showing 42 of 318" always reads against the same denominator. No singular special-casing ("Showing 1 of 318" is correct English).
- Right: **"Clear all"** — `<button type="button">` styled as a text link, Body 14px/700 accent, `min-h-11 px-2` (touch target), no underline at rest, underline on hover/focus. Rendered ONLY when any of `q`, `genre`, `decade`, `min`, `avail`, `sort` is non-default (D-24). Clicking it resets every key → URL becomes bare via `router.replace`.

### Poster grid

- `<ul role="list" class="grid grid-cols-2 sm:grid-cols-3 md:grid-cols-4 lg:grid-cols-5 xl:grid-cols-6 gap-3 sm:gap-4 pb-12">` (D-20: 2/3/4/5/6; bottom padding 48px).
- Minimum supported viewport is 360px: 2 columns × ~158px each after 16px side padding and 12px gap.
- No pagination, no virtualisation, no infinite scroll (REQUIREMENTS out-of-scope). Every matching card renders; `loading="lazy"` on images is the only deferral.
- Order = sorted list from `src/lib/filters.ts`; the grid never re-sorts.

### Footer

- `border-t border-border mt-12 py-6` + container. `flex flex-col items-center gap-4 text-center sm:flex-row sm:justify-between sm:text-left`.
- Left: TMDB logo — `public/tmdb.svg` (the official "blue short" primary logo from TMDB's brand page, unmodified; served via `withBasePath("/tmdb.svg")`), `height 16px`, `alt="TMDB"`, wrapped in `<a href="https://www.themoviedb.org/" rel="noopener noreferrer" target="_blank">`.
- Right: attribution — Label 12px/400 muted. Copy verbatim: **"This product uses the TMDB API but is not endorsed or certified by TMDB."** (D-09 catalog `attribution` string; render the string from the catalog root so the two never drift.)
- Nothing else in the footer for Phase 1 (no seller contact — that is Phase 2's mailto).

## Component Specs

### Filter chip (`FilterChip`)

| State | Classes / behaviour |
|-------|---------------------|
| Base | `<button type="button">` `inline-flex items-center justify-center whitespace-nowrap rounded-full border px-3 min-h-11 md:min-h-9 text-sm transition-colors duration-200` |
| Default | `border-border bg-surface text-text font-normal` |
| Hover (pointer only) | `hover:border-text-muted` — no fill change |
| Selected | `border-accent bg-accent text-bg font-bold` |
| Focus | global `focus-visible` outline (2px accent, 2px offset) |
| Disabled | not used in Phase 1 (chips whose option would yield 0 results are still enabled — the empty state handles it) |

- Multi-select groups (Genre, Decade): `aria-pressed={selected}`. Selected chips are NOT reordered to the front — order is stable so muscle memory works.
- Single-select groups (Rating, Availability): `<fieldset role="radiogroup">` with each chip `role="radio" aria-checked`. Arrow keys move selection within the group.
- Chip label copy: see Copywriting Contract.
- Genre chips list every distinct genre present in the catalog (all statuses), alphabetical. Decade chips list every distinct decade present, ascending. Both are derived at build time from the card projection — never hard-coded.

### Availability segmented control

- Same `FilterChip` visuals but grouped in a `rounded-full bg-surface border border-border p-1 inline-flex gap-1` track; segment buttons drop their own border (`border-transparent`) so the track reads as one control. Selected segment: `bg-accent text-bg font-bold`. Segments: **Available** · **Sold** · **All** in that order (D-25 default Available).

### Sort select

Native `<select>`; see toolbar. Changing it writes `?sort=` (omitted when Popularity).

### Bottom sheet (`FilterSheet`, base–`sm` only, hidden at `md+`)

- Native `<dialog>` opened with `showModal()` (Claude's discretion: hand-rolled, no library). Element: `fixed inset-x-0 bottom-0 m-0 w-full max-w-none max-h-[85dvh] rounded-t-2xl border-t border-border bg-surface p-0 text-text`. `::backdrop { background: rgb(15 23 42 / 0.7) }`.
- Structure (`flex flex-col max-h-[85dvh]`):
  1. **Header** `flex items-center justify-between px-4 h-14 border-b border-border`: title **"Filters"** (Heading 16/700 Archivo) + close `<button aria-label="Close filters">` 44×44 with `X` icon 20px muted. A 4px×36px muted drag-handle bar centered above the title is decorative (`aria-hidden`); no drag-to-dismiss behaviour is required.
  2. **Body** `flex-1 overflow-y-auto px-4 py-6 flex flex-col gap-6`: the four chip groups, each with a Heading 16/700 `<legend>` and a `flex flex-wrap gap-2` chip row. Order: Availability, Genre, Decade, Rating (same as desktop).
  3. **Footer** `sticky bottom-0 flex items-center gap-4 border-t border-border bg-surface px-4 py-3 pb-[calc(12px+env(safe-area-inset-bottom))]`: **"Reset"** text button (Body 14/700 muted, `min-h-11 px-2`) + apply `<button>` `flex-1 h-12 rounded-lg bg-accent text-bg text-base font-bold` labelled **"Show {n} results"** (n = live count for the draft filter state; "Show 1 result" when n = 1; "Show 0 results" when n = 0 — button stays enabled so the visitor lands on the empty state with its Clear filters affordance).
- **Draft/commit model:** chip taps inside the sheet mutate a local draft; the apply button commits the draft to the URL in one `router.replace` and closes the sheet. Close (X), Escape, and backdrop click discard the draft. "Reset" clears the draft to defaults (does not touch `q` or `sort`, which live in the toolbar). Opening the sheet seeds the draft from the current URL.
- Focus: `showModal()` traps focus natively; on open, focus the close button; on close, return focus to the Filters button. Body scroll is locked while open (`overflow: hidden` on `<html>` via a class toggled in an effect).
- Motion: `translateY(100%) → 0` over 200ms `ease-out` on open, using `@starting-style` (Tailwind `starting:` variant) — no JS animation library. Reduced motion: sibling `globals.css` already forces `transition-duration: 0.01ms`.

### Poster card (`MovieCard`)

```
<li>
  <Link href="/movie/{slug}/"                       ← next/link; basePath applied by Next (D-28)
     class="group block h-full rounded-xl border border-border bg-surface overflow-hidden
            transition-colors duration-200 hover:border-accent focus-visible:border-accent">
    <div class="relative aspect-[2/3] bg-surface">           ← poster box, always this ratio
      <img src={posterUrl(posterPath,"w342")} alt="" width=342 height=513
           loading="lazy" decoding="async"
           class="h-full w-full object-cover [.sold_&]:grayscale [.sold_&]:opacity-60" />
      {status==="sold"     && <SoldRibbon/>}
      {status==="reserved" && <ReservedPill/>}
    </div>
    <div class="p-2 sm:p-3">
      <h3 class="font-[family-name:var(--font-archivo)] text-sm font-bold leading-[1.5] line-clamp-2 min-h-[42px]">{title}</h3>
      <p class="mt-1 flex items-center gap-2 text-xs text-text-muted tabular-nums">
        <span>{year}</span>
        {rating && <RatingBadge/>}
      </p>
      <div class="mt-2 flex flex-wrap gap-1">
        <PriceChip/> <ConditionChip/>
      </div>
    </div>
  </a>
</li>
```

- Link: `next/link` `<Link href={`/movie/${slug}/`}>` (basePath applied automatically by Next; D-28). The whole card is the single tap target (D-17). Accessible name = title text (image `alt=""` prevents double announcement; the card's `<h3>` is the name).
- `width`/`height` attributes (342×513) plus the `aspect-[2/3]` wrapper guarantee zero CLS (CAT-02).
- `onError` on the `<img>` swaps to the placeholder body (same as no `posterPath`), so a dead CDN path never shows a broken-image glyph.
- Hover: border → accent, 200ms. No scale transform on the poster (sibling scales 1.02 on project previews; skipped here because 300 posters transforming on scroll-hover is jittery on trackpads). No hover-only content (D-17).
- Sold card: add class `sold` on the `<a>`; title color → muted; see SOLD treatment.

### Rating badge (`RatingBadge`)

- `inline-flex h-5 items-center gap-1 rounded border border-border bg-bg px-1.5 text-xs font-bold text-text tabular-nums`. `Star` icon 12px muted (`aria-hidden`).
- Copy: **"IMDb 8.2"** when `ratings.imdb` is set, else **"TMDB 7.9"** (D-06 source label). One decimal always (`toFixed(1)`). Omitted entirely when both are null — no dash placeholder.
- Accessible: `aria-label="IMDb rating 8.2 out of 10"` / `"TMDB rating 7.9 out of 10"`.

### Price chip (`PriceChip`)

- `inline-flex h-5 items-center rounded border border-border bg-bg px-1.5 text-xs font-bold text-text tabular-nums`.
- Copy: `Intl.NumberFormat("en-CA", { style: "currency", currency })` with `minimumFractionDigits: 0, maximumFractionDigits: 2` → **"$12"**, **"$12.50"** (D-05). Non-CAD currencies render as Intl gives (e.g. "US$12") — no override.
- `priceCents === null` → **"Ask"** in `text-text-muted font-normal`.
- `status === "sold"` → **"Sold"** in `text-text-muted font-normal` (replaces price, D-19). Reserved keeps its price.

### Condition chip (`ConditionChip`)

- `inline-flex h-5 items-center rounded border border-border bg-transparent px-1.5 text-xs font-normal text-text-muted`.
- Copy (D-03): `new` → **New**, `like-new` → **Like New**, `very-good` → **Very Good**, `good` → **Good**, `acceptable` → **Acceptable**.

### Placeholder poster (`PosterPlaceholder`)

- Rendered inside the same `aspect-[2/3]` box when `posterPath` is null or the image errors (D-18).
- `flex h-full w-full flex-col items-center justify-center gap-2 bg-surface p-4 text-center`.
- `Film` icon 32px `text-border` (faint by token, not by opacity), `aria-hidden`.
- Title: Archivo 14px/700 `text-text line-clamp-4`. Year: 12px/400 muted on the next line.
- Because the caption below also shows title and year, the placeholder box content is `aria-hidden="true"` (decorative repetition).

### SOLD treatment (`SoldRibbon`)

- Poster `<img>`: `grayscale opacity-60` (D-19).
- Ribbon: `absolute left-[-36px] top-[18px] w-[140px] -rotate-45 bg-accent-warm py-1 text-center text-xs font-bold uppercase tracking-wider text-bg shadow-sm` with `overflow-hidden` on the poster box clipping the ends. Copy: **"SOLD"**. `aria-hidden` — the price chip's "Sold" text carries the semantic; additionally the card `<a>` gets `aria-description="Sold"` so screen readers hear it once.
- Caption: title `text-text-muted`; price chip shows "Sold" (see Price chip); condition chip unchanged.

### Reserved treatment (`ReservedPill`)

- `absolute left-2 top-2 h-5 rounded-full bg-accent-warm px-2 text-xs font-bold text-bg` inside the poster box. Copy: **"Reserved"**. No desaturation; price chip unchanged (D-02, D-19). Card is included under the Available filter.

### Empty state (`EmptyState`)

- Rendered in place of the grid (not inside it) when the filtered list is empty: `flex flex-col items-center py-16 text-center`.
- `SearchX` icon 40px muted `aria-hidden`; heading **"No matches"** (Heading 16/700 Archivo, `mt-4`); body **"Try a different search or fewer filters."** (Body 14 muted, `mt-1`); button **"Clear filters"** (`mt-4 h-11 rounded-lg bg-accent px-4 text-sm font-bold text-bg`) — same reset action as "Clear all" (clears `q` too).
- The result-count line above still renders ("Showing 0 of 318") and its own "Clear all" is visible; both controls do the same thing.

### Loading skeleton (Suspense fallback)

- Rendered by `page.tsx` as the `<Suspense fallback>` around the client grid (D-27). Must occupy the same boxes as the real UI so hydration causes no shift:
  1. Toolbar shell: same sticky container; a `h-11 flex-1 rounded-lg bg-surface` bar and a `h-11 w-24 rounded-lg bg-surface` bar (non-interactive `div`s, `aria-hidden`).
  2. Count line: `h-5 w-32 rounded bg-surface`.
  3. Grid: identical grid classes; **12** skeleton cards, each `rounded-xl border border-border overflow-hidden` with an `aspect-[2/3] bg-surface` box and a caption containing a `h-[42px]` block (two `h-3.5 rounded bg-surface` bars, widths 90% / 60%) and a `h-5 w-16 rounded bg-surface` bar.
- Animation: `animate-pulse` on the skeleton root; neutralised automatically under reduced motion by the sibling `globals.css` rule.
- `role="status" aria-label="Loading catalog"` on the fallback root; `aria-busy="true"` on `<main>` while the fallback shows.

## Interaction Contract

| Interaction | Behaviour |
|-------------|-----------|
| Type in search | Filters on every keystroke (D-23); URL `q` updated with `router.replace` (no history entries). Diacritics- and case-insensitive substring on `title` and `originalTitle` |
| Toggle a chip (desktop) | Immediate: URL updated, grid re-renders, count line announces via `aria-live` |
| Toggle a chip (sheet) | Draft only; apply button label updates live; commit on "Show N results" |
| Change sort | Immediate; `sort` omitted from URL when Popularity |
| Clear all / Clear filters / Reset | Resets to bare URL (Reset in sheet resets the draft only) |
| Tap a card | Navigates to `/movie/{slug}/` (may 404 until Phase 2). Filter state survives in the referring URL so Back restores the view (D-26) |
